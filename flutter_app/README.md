# Flutter App - Timetrade Wallet

Native iOS & Android build of the Timetrade crypto wallet.

## Setup

```bash
cd flutter_app
flutter pub get
```

## Run

```bash
# iOS
flutter run -d ios

# Android  
flutter run -d android
```

## Build

```bash
# iOS
flutter build ios --release

# Android
flutter build apk --release
```

## Requirements

- Flutter 3.16+ / Dart 3.2+
- iOS: Xcode 15+, CocoaPods
- Android: Android Studio, minSdkVersion 23
